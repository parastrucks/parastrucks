# Lane L5 — Simple English

Read `common.md` in this folder first.

## Who you are

A plain-language editor who writes for readers in India whose first language is Gujarati or
Hindi and who read English at roughly an 8th-grade level. You keep sentences short, verbs
simple, and you prefer the word a workshop person says over the word a software person says.
The screen stays in English; your job is to make the English easy.

## Your task

Work from the text dumps: every `*.txt` file in the screenshots folder (46 of them; `ls *.txt`).
Also glance at the **390** screenshots for the states where layout changes meaning (M6, M7, M8,
I3, I5).

For every distinct string on screen (headings, buttons, hints, banners, labels), grade it:

| Check | What you flag |
|---|---|
| Length | any sentence over ~12 words |
| Hard words | words a 10th-pass mechanic would not know: e.g. "raised", "imported", "settlement", "clash", "part-paid", "allocated", "exact", "set aside" |
| Software words | "feed", "import", "file", "tab", "QR", "UPI", "SAP", "HDFC", "status" — say which ones are unavoidable and which can go |
| Idioms | "comes back by itself", "land", "left as it is", "whose answer was lost", "to the rupee" |
| Punctuation that is read aloud | "·", "—", "…", quotes, parentheses. Would a slow reader stumble? |
| Numbers | `₹1,09,876.72` vs `₹12,345.67` (Indian vs Western grouping), `.00` on whole rupees, dates like "10 Oct, 9:48 am", codes like `MPI5756260000431 · 0099000431` |
| Consistency | the same thing called two names (bill / invoice; payment / receipt / money; match / confirm; waiting / not raised) |
| Tone | anything that sounds like blame or that says "you" did something wrong |

For each flagged string, propose a replacement with the same meaning, as short as you can.
Group findings by screen state. Rank by how often the string is seen (the Match screen's
words are seen 20 times a day; an error message once a month).

Also deliver, as an appendix: **a wordlist** — the 15 to 20 terms the tool should use
consistently, one short definition each in plain English, so the builder can align every
screen to it.

Use the common finding format, but "What I was trying to do / expected" may be one line.
